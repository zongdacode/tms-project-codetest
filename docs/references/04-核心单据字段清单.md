## 1. 物流订单 logistics_order

### 1.1 主表

|---|---|---|---|---|
| order_no | VARCHAR(32) | 是 | 单号规则生成 / PES单号 | 接口来源沿用源单号；手工/导入按租户单号规则生成；只读 |
| source_system ★ | VARCHAR(20) | 是 | PES / MES / SAP / REPORT(微通道报表平台) / MANUAL(手工) / IMPORT(导入) | 决定字段可编辑性：接口单必填项以源数据为准，异常项进异常订单模块修正 |

| ship_warehouse_id | BIGINT | 是 | 仓库主数据 | 源单带出可改；**退货单 = 退货目的仓**（镜像后） |

| customer_name | VARCHAR(128) | 是 | — | 弹窗选择客户带出 |
| consignee_name | VARCHAR(64) | 是 | 收货联系人 | 选客户带出，可手改 |
| consignee_phone | VARCHAR(20) | 是 | — | 同上 |

| delivery_date | DATE | 是 | 送货日期 | 源单带出 |

| required_loading_time | DATETIME | 否 | 要求装货时间 | — |

| transport_mode | VARCHAR(20) | 是 | SELF_PICKUP 自提 / DELIVERY 配送 | 确认时可改；自提单不生成提货/配送任务单，仅打印送货单+签收 |
| shipping_method | VARCHAR(20) | 是 | LTL 零担 / FTL 整车(专车) / EXPRESS 快递 / FORWARDER 货代 | 决定计费模型与运单字段（车型/车数、快递单号、箱型）；确认时可改 |

| pool_status | VARCHAR(20) | 是 | NONE 无 / WAITING 待拼车 / PENDING_CONFIRM 待确认 / POOLED 已拼车 | 「发起拼车」→WAITING；对方发起申请→本方 PENDING_CONFIRM；确认→双方 POOLED；未建运单前可取消回 WAITING |
| pool_id | BIGINT | 否 | 拼车池单ID | — |
| partner_tenant_id | BIGINT | 否 | 对方工厂 | 拼车对方属主；建单后运单按关联属主对其可见 |
| partner_order_id | BIGINT | 否 | 对方订单 | — |
| total_weight | DECIMAL(18,4) | 否 | kg | 明细汇总只读 |
| total_volume | DECIMAL(18,4) | 否 | m³ | 同上 |
| total_boxes | INT | 否 | — | 同上；零头箱>0 时=箱数+1 |
| pallet_count | INT | 否 | 托数 | 打托时计算 |
| order_status | VARCHAR(20) | 是 | ABNORMAL 异常 / PENDING 待确认 / CONFIRMED 已确认 / WAYBILLED 已生成运单 / PARTIAL_WAYBILLED 部分生成 / CANCELED 已取消 | 接口校验失败→ABNORMAL 进异常订单模块；**仅 CONFIRMED 可分单**；批量确认限同客户可改地址 |
| salesperson | VARCHAR(64) | 否 | — | — |
| business_dept | VARCHAR(64) | 否 | 默认当前部门 | 部门维度统计用 |
| remark | VARCHAR(500) | 否 | — | — |
| attachments | JSON | 否 | 文件/图片，多个 | 对象存储元数据（类型/上传人） |

## 8. 相对 PRD 的结构修订（核对时注意）

1. 运单 6 个平行三态字段（分配/提货/干线/中转/配送/签收）**不落库**，改为主状态机 + 事件时间线聚合展示；
2. 运单 15+ 费用散列字段收敛为 waybill_fee 子表，费用项字典化；
3. 地址统一省市区编码+经纬度+围栏 ID（一址一 ID）；
4. 新增参与方/权限物化字段（owner_tenant_id / carrier_org_id / customer_org_id / driver_id / route_id / eff_*_park），第一版建表即含，配套索引：`(owner_tenant_id, waybill_date)`、`(carrier_org_id, waybill_date)`、`(customer_org_id, status)`、`(driver_id, task_status)`。
