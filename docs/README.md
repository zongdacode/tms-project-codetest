## 术语速查

完整定义见 [11-glossary.md](11-glossary.md)。

| 术语 | 一句话 |
|---|---|
| 计划表（order_plan） | TMS 内独立的单据订单/计划协调表，承载多系统主单关键节点状态，订单中心雏形 |
| 业务单号 + 行号 | 跨系统唯一关联键，所有系统必须同时存储 |
| 事件语义接口 | 以"发生了什么事实"（出库完成/签收完成/订单取消）为契约的接口，当前经 HTTP 同步调用 |
| 本地事件表 | 发送方落库的事实记录，配合幂等消费与重试 |
| 履约跟踪视图 | 只读聚合主单与运输执行状态的查询视图，服务客服/运营，不承载业务逻辑 |
| 冲销 | 对已发生业务事实的抵消动作，独立状态迁移，不回退原状态 |

## 文档维护规则

1. 任何 `[已决策]` 的变更：在 01 中新增或修订 ADR（旧 ADR 标记"已被 ADR-xxx 取代"，不删除），并同步更新受影响文档。
2. 任何 `[待定]` 落定：把结论写成新 ADR，并从正文移除待定标记。
3. 流程/接口/表结构变更：先改本套文档，再改代码；文档与代码不一致时以本问题为缺陷处理。
4. 文档内 Mermaid 图必须与正文表格一致，评审时逐条核对。
